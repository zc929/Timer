# 定时助手 Timer

Windows 定时操作助手，支持关机、重启、注销、锁屏、休眠、睡眠、关闭显示器及打开文件。

[下载最新版](https://github.com/zc929/Timer/releases/latest) · [全部版本](https://github.com/zc929/Timer/releases)

## 下载

面向 Windows 10 2004（19041）及以上、Windows 11，x64。

在 Releases 页面选择版本，再下载以下附件之一：

- **安装版**：`Timer-Setup-<版本号>-x64.exe`，已包含所需运行时，默认按当前用户安装。
- **免安装版**：`Timer-win-x64-v<版本号>.zip`，完整解压后运行 `Timer.App.exe`。请保留全部 DLL、资源及子目录。

每版附带 `SHA256SUMS-<版本号>.txt` 校验文件。更新前请从托盘退出程序；密码锁定时需要先验证密码。

## 功能

- 七种计划：指定日期时间、每隔 X 天、每周、每月、每年、间隔及鼠标键盘空闲。
- 1.0.2 新增“打开文件”操作，通过 Windows 默认程序打开目标文件，支持全部七种计划。
- 执行前倒计时提醒，可取消本次执行。
- 密码锁定、系统托盘、开机自动启动。
- 简体中文、繁体中文及英文界面。
- 1.0.3 新增 GitHub 正式版更新检测，支持后台检查及手动检查，发现新版后可打开发布页下载。
- 本地保存任务和设置，支持备份恢复。
