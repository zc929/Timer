# 定时助手 Timer 1.0.3

Windows x64 正式版，支持 Windows 10 2004（19041）及以上和 Windows 11。

## 更新内容

- 新增 GitHub 正式版更新检测：启动后自动检查，后台每 6 小时复查，主界面右下角也可手动“检查更新”。
- 发现新版本时显示醒目的更新入口，点击打开对应 GitHub 发布页面，由用户选择下载和安装。
- 更新提醒独立于任务通知开关，密码锁定后仍可查看；后台检查不会唤出已隐藏到托盘的窗口。
- 更新提示支持简体中文、繁体中文和英文；保留正在编辑的设置输入，临时断网后保留已发现的新版提示。
- 只检测正式发布，忽略草稿和预发布版本；自动检查失败时保持安静，手动检查失败时显示提示。

## 下载与使用

- `Timer-Setup-1.0.3-x64.exe`：安装版，包含运行时，默认按当前用户安装。
- `Timer-win-x64-v1.0.3.zip`：免安装版，完整解压后运行 `Timer.App.exe`，请保留全部 DLL 与资源文件。
- `SHA256SUMS-1.0.3.txt`：上述两个文件的 SHA-256 校验值。

更新前请从托盘退出程序；已锁定时需要验证密码。程序不会自动下载或安装更新。

此仓库的版本标签归档发布说明、随包文档及校验文件。GitHub 自动生成的 Source code 归档仅包含这些文档；运行软件请下载上述 EXE 或 ZIP 附件。
