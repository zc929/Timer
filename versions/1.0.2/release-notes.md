# 定时助手 Timer 1.0.2

Windows x64 正式版，支持 Windows 10 2004（19041）及以上和 Windows 11。

## 更新内容

- 新增“打开文件”执行操作，通过文件选择窗口指定目标，并使用 Windows 默认程序打开。
- 支持全部七种任务计划；任务列表和执行前倒计时显示目标文件路径。
- 文件被移动、删除或无法访问时提示失败，不影响其他任务；修改文件目标同样受密码锁定保护。
- 保留全局及单任务通知开关、倒计时取消和简体中文、繁体中文、英文界面。
- 演示模式仅模拟文件操作，不实际打开目标文件。

## 下载与使用

- `Timer-Setup-1.0.2-x64.exe`：安装版，包含运行时，默认按当前用户安装。
- `Timer-win-x64-v1.0.2.zip`：免安装版，完整解压后运行 `Timer.App.exe`，请保留全部 DLL 与资源文件。
- `SHA256SUMS-1.0.2.txt`：上述两个文件的 SHA-256 校验值。

更新前请从托盘退出程序；已锁定时需要验证密码。
