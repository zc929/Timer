# 定时助手 Timer 1.0.6

Windows x64 正式版，支持 Windows 10 2004（19041）及以上和 Windows 11。

## 更新内容

- 精简主界面任务卡片，移除列表中的任务通知开关，保留任务启用、编辑及删除操作。
- 单个任务的通知开关可在新建或编辑任务窗口调整；全局“任务通知”开关仍在设置页中管理。

## 下载与使用

- `Timer-Setup-1.0.6-x64.exe`：安装版，包含运行时，默认按当前用户安装。
- `Timer-win-x64-v1.0.6.zip`：免安装版，完整解压后运行 `Timer.App.exe`，请保留全部 DLL 与资源文件。
- `SHA256SUMS-1.0.6.txt`：上述两个文件的 SHA-256 校验值。

更新前请从托盘退出程序；已锁定时需要验证密码。使用 1.0.3 及以上版本时，也可通过主界面右下角“检查更新”打开本发布页。
