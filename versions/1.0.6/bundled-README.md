# 定时助手 Timer 1.0.6 正式版

使用 C#、.NET 8 和 WinUI 3 编写的 Windows 桌面程序，支持定时关机、重启、注销、锁屏、休眠、睡眠、关闭显示器及打开文件。

正式版安装包为 `artifacts\Timer-Setup-1.0.6-x64.exe`，使用 Inno Setup 制作。安装向导支持简体中文、繁体中文和英文，可选择是否添加桌面快捷方式（默认不勾选），安装完成页可选择是否启动定时助手（默认勾选）。

安装默认放在当前用户的 `%LOCALAPPDATA%\Programs\Timer`，无需管理员权限。可通过 Windows“已安装的应用”卸载，卸载时提供两种选择：

- **卸载但保留设置（默认）**：移除程序，保留任务、设置及密码数据，重新安装后可继续使用。
- **完整卸载**：移除程序，并删除 `%LOCALAPPDATA%\TimerAssistant` 中的任务、设置、密码数据、备份及日志，删除后无法恢复。

两种方式均仅移除指向本次安装的开机启动项。取消卸载不改动程序和数据；静默卸载默认保留数据。安装、更新或卸载前，请先从托盘退出定时助手；已锁定时需验证密码，安装程序不会强制关闭软件。已安装旧安装包的用户需先运行新版安装包更新，才会获得新的卸载选项。

也提供免安装压缩包 `artifacts\Timer-win-x64-v1.0.6.zip`。解压完整文件夹后运行 `Timer.App.exe`。

## 功能

- 在主界面新增、编辑、删除任务，单独启用或停用任务。
- 设置页“关于定时助手”提供“查看项目说明（GitHub）”链接，点击用默认浏览器打开 https://github.com/zc929/Timer；锁定状态下也可查看。
- 主界面使用完整宽度展示任务，右上角“设置”按钮打开设置页；通过“返回任务”按钮回到任务列表。
- “设置”左侧提供带状态图标的锁定按钮。锁定时设置并确认密码；新密码只允许半角英文字母、数字和标准英文符号，不接受空格、中文或全角字符。锁定后仍可查看任务和设置，但不能新增、编辑、删除、启停任务或修改设置。再次点击并输入正确密码后解锁。锁定状态及密码校验信息在重启后保留，已有任务照常执行，倒计时仍可取消。
- 新建/编辑任务框采用统一尺寸，切换执行计划时保持不变；较长内容在框内滚动。
- 执行操作选择“打开文件”后，点击“选择文件”指定目标，可配合全部七种计划使用；任务列表和倒计时均显示文件路径，文件通过 Windows 默认程序打开。文件被移动、删除或无法访问时会提示失败，不影响其他任务；修改目标文件也受密码锁定保护。
- 七种计划：指定日期时间、每隔 X 天、每周、每月、每年、间隔、鼠标键盘空闲。
- 执行前弹出置顶倒计时窗口，显示任务名称和操作；可以取消本次执行。
- 提醒居中显示在鼠标所在屏幕的工作区，避开任务栏。
- 设置中可统一修改所有任务的提前提醒时间，默认 30 秒，可填写 0–3600 的整数秒数；设为 0 则不显示提醒。
- 设置中提供全局“任务通知”开关，每个任务也有独立通知开关，可在新建/编辑窗口调整；主界面任务列表不显示通知开关。全局关闭后全部任务停止弹出执行前提醒，单任务开关禁用并保留原选择；全局重新开启后按各任务原选择生效。关闭通知不停止任务执行。新任务及从旧版本升级的任务默认开启通知。
- “已保存”等操作提示在窗口底部浮动显示，停留约 3 秒后淡出，不占页面空间；错误提示停留约 6 秒，也可手动关闭。
- 系统托盘菜单提供“打开主界面”和“退出”；关闭主窗口后继续在托盘运行。锁定状态下选择“退出”也必须验证密码，错误或取消时继续运行；验证退出不会解除锁定，下次启动仍需密码。
- 设置中可启用当前用户的开机自动启动。登录 Windows 后只显示托盘；手动启动显示主界面。
- 简体中文、繁体中文、英文界面，可在设置中立即切换。
- 界面使用 WinUI 默认字体，保持紧凑的字号、间距和控件布局，无需额外字体文件。
- 窗口设有最小尺寸，防止拖动缩小时挤乱布局；尺寸限制随 Windows 显示缩放调整。
- 启动后自动检测 GitHub 正式版本，后台每 6 小时复查一次；主界面右下角可手动“检查更新”。发现更新时显示持续醒目的入口，点击打开对应 GitHub 发布页面。更新提醒不受任务通知开关影响，锁定后仍可查看；不会自动下载或安装，也不会唤出隐藏到托盘的窗口。
- 本地保存任务及设置，采用原子替换和上一个版本的备份；损坏时显式提示恢复或读取失败。

## 环境及构建

目标为 **Windows 10 2004 / build 19041 及以上、Windows 11，x64**。开发使用 .NET 8 SDK；Windows App SDK 版本固定为 `1.8.260101001`。首次构建需要访问 NuGet。也可以用安装了 Windows 桌面开发及 WinUI 开发组件的 Visual Studio 2022 打开 `Timer.sln`。

在项目根目录的 PowerShell 中执行：

```powershell
# 编译应用和测试项目
.\scripts\build.ps1

# 运行纯托管测试；不会执行任何真实关机、电源或锁屏操作
.\scripts\test.ps1

# 检查图标字体是否包含全部自定义图标（可用 -FontPath 指定 Windows 10 字体副本）
.\scripts\test-icon-font.ps1

# 可选：自动渲染三语界面及七类任务表单；先退出当前测试用户正在运行的定时助手
.\scripts\test-ui.ps1

# 可选：在 Windows 桌面验证原生托盘菜单（不执行电源操作）
.\scripts\test-tray.ps1

# 发布包含 .NET 和 Windows App SDK 运行时的 x64 程序
.\scripts\publish.ps1

# 发布并生成 Inno Setup 安装包（需安装 Inno Setup 6.3 或更新版本及中英文语言文件）
.\scripts\build-installer.ps1

# 已有完整、最新发布目录时，可跳过重新发布
.\scripts\build-installer.ps1 -SkipPublish

# 测试卸载数据选项，使用项目目录内的模拟数据，不接触实际任务及设置
.\scripts\test-uninstall-data.ps1

# 对实际交付的 ZIP 解压测试启动；先通过托盘退出已有定时助手
.\scripts\test-publish.ps1 -ArchivePath .\artifacts\Timer-win-x64-v1.0.6.zip
```

脚本优先使用 PATH 中可用的 .NET 8 或更新 SDK；没有可用 SDK 时，尝试项目内的 `.tools\dotnet\dotnet.exe`。使用本地 SDK 时，其缓存保存在 `.tools` 下。

默认发布目录为 `artifacts\Timer-win-x64`。本次 1.0.6 使用独立目录 `artifacts\Timer-win-x64-v1.0.6`，保留旧版目录。后续可通过 `publish.ps1 -PublishDirectory <路径>` 或 `build-installer.ps1 -PublishDirectory <路径>` 指定输出目录。保留整个目录及其中的 DLL、资源和运行时文件，运行 `Timer.App.exe`，不要仅复制 EXE。程序采用非打包部署，无需 MSIX 安装。

安装脚本为 `installer\Timer.iss`，版本号从应用项目读取，产物为 `artifacts\Timer-Setup-<版本号>-x64.exe`。构建脚本自动查找已安装的 Inno Setup，也可通过 `-CompilerPath 'C:\Program Files\Inno Setup 7\ISCC.exe'` 指定编译器。安装包包含完整运行时；静默安装不会自动启动应用。开机自动启动仍通过软件设置启用。

`Timer.App.pri` 是启动时必需的 WinUI 资源索引，其中包含编译后的 `App.xaml`。发布步骤会复制并检查该资源文件，不可从发布目录中删除。

## 界面与提醒

全局通知和任务通知均开启，且提前提醒时间大于 0 时，才显示执行前倒计时。关闭全局或任务通知会隐藏相应的已显示提醒，但不会取消该次执行或改变执行时间；重新开启后仍未到期的提醒可以继续显示。关闭通知的空闲任务达到设定空闲时长后直接执行。关闭一个显示中的提醒窗口只取消其中可见的任务，不影响已关闭通知的其他待执行任务。通知开关同样受密码锁定保护，锁定后仅可查看。

设置中的“提前弹窗提醒”对所有任务的后续提醒统一生效，已经开始的倒计时保持原有执行时间。新建/编辑任务中显示当前提醒时间。载入尚未设置全局提醒的历史数据时，会保留任务各自的提醒秒数，首次保存全局提醒后统一生效。

界面采用 WinUI 默认字体和紧凑布局。主窗口默认尺寸为 1008×720，最小尺寸为 900×660；提醒窗口最小尺寸为 468×360，均为包含标题栏的逻辑尺寸，随系统 DPI 缩放。新建/编辑任务框固定为 504×576，在主窗口最小尺寸下仍可完整显示，较长内容通过滚动查看。

按钮、任务列表和更新提醒中的自定义图标统一使用 Windows 10/11 自带的 `Segoe MDL2 Assets` 图标字体，避免 Windows 10 缺少 `Segoe Fluent Icons` 时显示方块；无需另装字体。界面文字仍采用系统默认字体。

程序的 EXE、窗口标题栏及系统托盘统一使用青绿色时钟图标，外部背景透明，ICO 提供 16–256 像素的多种尺寸。源文件为 `output/icons/timer-icon.ico` 和 `output/icons/timer-icon.png`。主按钮在普通、悬停、按下状态下使用青绿色色阶与白色文字，禁用时文字和图标跟随系统禁用样式。

操作反馈使用独立浮动提示层：“已保存”等提示停留 3 秒后用 0.5 秒淡出，错误提示停留 6 秒后淡出。提示出现、关闭和自动消失均不挤动任务列表或设置页；保存提醒设置时保留当前输入框和焦点。重复提示会重新计时。关闭系统动画时仍自动消失，但跳过淡出动画。

## GitHub 版本检测

更新来源固定为 [zc929/Timer 的 Releases](https://github.com/zc929/Timer/releases)，配置位于 `src/Timer.App/Services/UpdateConfiguration.cs`。通过 GitHub 公开接口读取最新正式 Release，无需账号或令牌。请在 Releases 发布新版本并使用 `v1.0.6` 或 `1.0.6` 这类数字标签；仅创建 Git 标签或上传源代码不会成为可检测的正式发布。比较时使用数字版本，支持可选的 `v` 前缀、2–4 段数字和构建元数据，忽略草稿及预发布版本。

检查异步执行，15 秒超时；自动检查失败时保持安静，手动检查失败时显示浮动提示。已发现的新版本会在临时断网后保留提醒；更新到达时不重建当前任务或设置页面。退出程序会停止检查并取消未完成的请求。演示模式不会自动连接 GitHub，测试使用模拟响应与链接打开器。
## 密码锁定

主界面和设置页顶部均显示锁定状态图标。每次锁定时输入密码并再次确认，解锁时核对密码。新密码为 1–128 个可见 ASCII 字符（`!` 至 `~`），允许 A–Z、a–z、0–9 和半角英文符号，区分大小写，不接受空格、中文、全角字符、表情、换行等字符。无效输入会明确提示，不会通过去除或替换字符来接受密码。

密码错误、确认不一致或取消弹窗均不改变锁定状态。解锁后可在下次锁定时设置新密码；已锁定时不能通过重新设置密码绕过校验。锁定、解锁都会保存到本地数据，保存失败时保留原状态并显示错误提示。任务调度及提醒取消继续正常工作。

载入历史数据时，已经保存的密码仍可用于解锁和退出，下次设置密码时采用当前字符规则。历史数据中的无密码锁定保持锁定，首次点击时先补设密码，再以该密码解锁。

锁定时从托盘选择“退出”，会显示主窗口并弹出密码验证。输错或取消不会停止调度、关闭提醒或移除托盘图标；输入正确密码后才退出。退出验证仅确认密码，不解除锁定或清除密码校验信息，因此重新启动仍为锁定状态。重复选择退出只保留一个验证流程；已有其他弹窗时需先完成或取消该弹窗。旧版无密码锁定需先设置密码，再单独验证退出。主窗口的关闭按钮仍仅隐藏到托盘，不退出程序。

密码不以明文保存在任务文件或备份中，使用 16 字节随机盐和 PBKDF2-HMAC-SHA256（600,000 次迭代、32 字节输出），通过固定时间比较验证。工作因子参考 [OWASP 密码存储指南](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)，比较使用 [.NET CryptographicOperations.FixedTimeEquals](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.cryptographicoperations.fixedtimeequals)。

## 启动及安全预览

```powershell
# 手动启动并显示主窗口
.\artifacts\Timer-win-x64\Timer.App.exe

# 模拟登录启动，仅显示托盘
.\artifacts\Timer-win-x64\Timer.App.exe --startup

# 演示模式：正常调度及倒计时，结束时只显示结果，不执行电源命令或打开文件
.\artifacts\Timer-win-x64\Timer.App.exe --dry-run
```

同一用户、同一 Windows 会话只运行一个实例。手动再次启动会打开已有实例的主界面；命令行参数不会改变已有实例的运行模式。使用 `--dry-run` 前，先通过托盘菜单退出已有实例。演示模式使用程序目录下独立的 `DryRunData` 数据目录，并禁用开机启动设置；演示任务不会写入正常任务数据，也不会执行实际关机、注销、休眠、睡眠、锁屏、关闭显示器或打开文件操作。

启用开机启动后，程序在当前用户的 Windows 登录启动项中登记带 `--startup` 的完整程序路径。移动发布目录后，请在新位置启动程序，关闭并重新启用“开机自动启动”，以更新路径。

## 调度规则

通知开关的保存、旧数据默认开启、任务独立性、全局开关优先级，以及关闭通知后的日历/间隔/空闲执行时机均有自动化测试；界面测试还验证禁用状态、锁定限制、保存失败回滚、既有倒计时隐藏及保留执行时刻。

| 计划 | 行为 |
| --- | --- |
| 自定义日期时间 | 指定本地日期和时间，仅执行一次；开始提醒后即视为该次已处理。 |
| 每天 / 每隔 X 天 | 从选择的开始日期计算，每隔 X 天在固定时间执行，不因月份变化改变间隔。 |
| 每周 | 在选中的星期一至星期日执行，至少选择一天。 |
| 每月 | 在指定日和时间执行；例如 31 日任务会跳过没有 31 日的月份。 |
| 每年 | 在指定月日和时间执行；2 月 29 日只在闰年执行。 |
| 间隔 | 按实际经过的 X 小时 X 分钟计算，时长必须大于零；编辑或重新启用后重新计时。 |
| 空闲 | 当前登录会话的鼠标键盘空闲达到时长后，开始提醒；一次执行或取消后，需要新的输入活动才能再次触发。 |

- 日历计划使用电脑的本地时区。夏令时开始时不存在的时间向后移动一个时差；夏令时结束时重复出现的时间只取第一次。
- 提醒中的取消仅影响本次执行，循环任务的后续计划继续保留；一次性任务本次取消后保持停用。关闭提醒窗口会取消其中的所有待执行项。
- 新建任务已进入提前提醒区间时，会立即显示剩余倒计时，执行时间保持为设定时间。
- 启动或从睡眠恢复时跳过已错过的执行，不补执行；暂停或休眠期间的倒计时不会恢复为突然执行的旧操作。
- 程序不会唤醒电脑，也不会注册系统计划任务。在托盘运行时任务继续工作；从托盘退出后，全部任务停止，直到再次启动程序。

## 数据与故障处理

数据目录：`%LOCALAPPDATA%\TimerAssistant`

- `tasks.json`：带版本信息的任务和设置文件。
- `tasks.json.bak`：上一个已保存版本；存在旧版本后才会生成。
- `error.log`：运行错误日志。

主文件无法读取时，程序尝试从备份恢复，并在界面显示提示。主文件和备份都无法读取时，程序保留文件并停止调度，避免在未知数据状态下执行操作。需要手动维护数据时，先通过托盘退出程序，再备份该目录。

休眠需要 Windows 已启用休眠；睡眠和显示器关闭依赖硬件、电源策略及会话状态。组织策略或当前账户权限可能阻止相关操作。程序不会强制结束其他应用，未保存文档或 Windows 自身的提示可能阻止关机、重启或注销。显示器关闭后，输入活动或其他应用可以重新点亮显示器。
