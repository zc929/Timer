# 定时助手 Timer 1.0.5

Windows x64 正式版，支持 Windows 10 2004（19041）及以上和 Windows 11。

## 更新内容

- 在设置页“关于定时助手”中新增“查看项目说明（GitHub）”链接，使用默认浏览器打开 [Timer 项目主页](https://github.com/zc929/Timer)。
- 链接文案支持简体中文、繁体中文和英文；密码锁定状态下仍可查看项目说明。

## 下载与使用

- `Timer-Setup-1.0.5-x64.exe`：安装版，包含运行时，默认按当前用户安装。
- `Timer-win-x64-v1.0.5.zip`：免安装版，完整解压后运行 `Timer.App.exe`，请保留全部 DLL 与资源文件。
- `SHA256SUMS-1.0.5.txt`：上述两个文件的 SHA-256 校验值。

更新前请从托盘退出程序；已锁定时需要验证密码。使用 1.0.3 及以上版本时，也可通过主界面右下角“检查更新”打开本发布页。

此仓库的版本标签归档发布说明、随包文档及校验文件。GitHub 自动生成的 Source code 归档仅包含这些文档；运行软件请下载上述 EXE 或 ZIP 附件。
