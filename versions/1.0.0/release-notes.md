# 定时助手 Timer 1.0.0

Windows x64 正式版，支持 Windows 10 2004（19041）及以上和 Windows 11。

## 功能与更新

定时助手首个正式版，支持定时关机、重启、注销、锁屏、休眠、睡眠及关闭显示器。

- 七种计划：指定日期时间、每隔 X 天、每周、每月、每年、间隔及鼠标键盘空闲。
- 执行前倒计时提醒，可取消本次执行；支持统一设置提醒秒数。
- 密码锁定、系统托盘、开机自动启动及简体中文、繁体中文、英文界面。
- 本地任务和设置保存、备份恢复。
