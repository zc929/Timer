# 定时助手 Timer 1.0.4

Windows x64 正式版，支持 Windows 10 2004（19041）及以上和 Windows 11。

## 更新内容

- 修复 Windows 10 缺少 Segoe Fluent Icons 字体时，自定义图标可能显示为方块的问题。
- 按钮、任务列表及更新提醒中的图标统一使用系统自带的 Segoe MDL2 Assets，无需另外安装字体。
- 界面文字继续使用系统默认字体，保留定时任务、文件打开和 GitHub 更新检测功能。

已核验全部 16 个自定义图标的字体映射，并完成 Windows 11 下的 WinUI 界面渲染检查；尚未进行 Windows 10 实机回归。

## 下载与使用

- `Timer-Setup-1.0.4-x64.exe`：安装版，包含运行时，默认按当前用户安装。
- `Timer-win-x64-v1.0.4.zip`：免安装版，完整解压后运行 `Timer.App.exe`，请保留全部 DLL 与资源文件。
- `SHA256SUMS-1.0.4.txt`：上述两个文件的 SHA-256 校验值。

更新前请从托盘退出程序；已锁定时需要验证密码。1.0.3 用户也可通过主界面右下角“检查更新”打开本发布页。
