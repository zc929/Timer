# 定时助手 Timer 1.0.1

Windows x64 正式版，支持 Windows 10 2004（19041）及以上和 Windows 11。

## 功能与更新

- 新增全局“任务通知”开关及每个任务的独立通知开关，可在任务列表或编辑窗口调整。
- 关闭全局通知时停用全部执行前提醒，并保留各任务的通知选择；重新开启后按原选择生效。
- 关闭通知不会取消任务或改变执行时间；关闭空闲任务通知后，达到空闲时长直接执行。
- 已显示的提醒随通知设置隐藏或恢复；通知设置受密码锁定保护。
- 新任务及旧数据迁移默认开启通知。

- Timer-Setup-1.0.1-x64.exe：安装版，包含运行时，默认按当前用户安装。
