# 定时助手 Timer 1.0.7

Windows x64 正式版，支持 Windows 10 2004（19041）及以上和 Windows 11。

## 更新内容

- 设置页新增全局“强制关闭应用”开关，默认关闭，从旧版本升级后也保持关闭。
- 开启后，关机和重启任务在实际执行时强制关闭应用；其他操作不受影响。切换开关本身不会关闭应用。
- 开关受密码锁定及只读状态保护，保存失败时恢复原状态。

**开启此选项后，关机或重启可能导致未保存内容丢失。** 此选项不改变错过任务的处理规则，也不负责唤醒睡眠中的电脑。

## 下载与使用

- `Timer-Setup-1.0.7-x64.exe`：安装版，包含运行时，默认按当前用户安装。
- `Timer-win-x64-v1.0.7.zip`：免安装版，完整解压后运行 `Timer.App.exe`，请保留全部 DLL 与资源文件。
- `SHA256SUMS-1.0.7.txt`：上述两个文件的 SHA-256 校验值。

更新前请从托盘退出程序；已锁定时需要验证密码。使用 1.0.3 及以上版本时，也可通过主界面右下角“检查更新”打开本发布页。
